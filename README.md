## Overview

A Discord bot for automating useful server tasks for gamers, crafters, and chaotic little gremlins who want less repetitive admin and more actual doing.

## Features

- Slash command support
- Server automation tools
- Interactive bot responses
- Easy local setup with environment variables
- Modular command and event structure

## Tech Stack

- Node.js
- Discord API / Discord Developer Portal
- Discord bot framework or library used in this project

## Prerequisites

Before starting, make sure you have:

- Node.js installed
- A Discord application created in the Discord Developer Portal
- A bot token
- A test server where you can install the bot
